# Rama de datos — Seguimiento de Pendientes

Esta rama **no contiene código de la app**. Es el almacén persistente del sistema de
seguimiento de pendientes de Adrián.

- `estado.json` — la libreta de pendientes (fuente de verdad del estado).
- `runbook.md` — la lógica operativa que siguen la skill interactiva y las tareas automáticas.

No fusionar a `main`. La skill vive en `.claude/skills/seguimiento-pendientes/` en `main`.
